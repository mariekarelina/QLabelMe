# Руководство пользователя QLabelMe

## Интерфейс программы

### Область изображения

В центральной области отображаются текущее изображение, фигуры и их управляющие узлы. Здесь выполняются рисование, редактирование и перемещение разметки.

### Меню и панели инструментов

- **Файл** — открытие рабочей папки, сохранение текущей разметки и выход
- **Правка** — создание фигур, операции с разметкой и управление отображением
- **Настройка** — настройки приложения и проекта
- **Справка** — руководство пользователя и сведения о программе

**Ctrl + M** скрывает или показывает главное меню. Если меню скрыто, той же комбинацией его можно вернуть.

На панели инструментов расположены кнопки создания пяти типов фигур и кнопки отмены и повтора действий.

### Список файлов

Список показывает изображения выбранной папки. Выберите файл из списка для перехода к нему. Для последовательного просмотра используйте **A** и **D**.

При открытии изображения программа загружает его разметку из соответствующего YAML-файла, если он существует. Несохраненные изменения открытых изображений сохраняются в памяти до закрытия рабочей папки или программы.

Значки состояния перед именем файла описаны в разделе **«Сохранение разметки»**.

### Список фигур

Список показывает фигуры текущего изображения с их номерами и классами. Выделение в списке связано с выделением на изображении.

Через контекстное меню списка можно скрыть или показать разметку и удалить выбранные фигуры. У скрытого элемента появляется пометка **[скрыто]**.

### Координаты, история действий и классы

Панель координат позволяет просматривать координаты разметки. История действий показывает действия текущего изображения.

### Строка состояния

Внизу окна отображаются текущий режим, состояние автосохранения, размеры изображения и сведения о версии программы. Временные подсказки могут пояснять следующий шаг, например при объединении линий.

## Открытие и просмотр изображений

### Рабочая папка

Нажмите **Ctrl + O** и выберите папку с изображениями. Программа запоминает последнюю открытую папку для следующего выбора.

Список классов относится к рабочей папке. При открытии другой папки программа загружает ее собственный файл **classes.yaml**.

### Переход между изображениями

- **D** — следующее изображение
- **A** — предыдущее изображение
- Щелчок по файлу в списке — переход к выбранному изображению

Последовательный переход зациклен: после последнего файла открывается первый, перед первым — последний.

Переход к другому изображению сам по себе не означает сохранение изменений на диск. Проверяйте индикаторы файлов и используйте ручное или автоматическое сохранение.

### Масштаб и перемещение

- Удерживайте **Ctrl** и вращайте колесо мыши для изменения масштаба около курсора
- Используйте **Ctrl + плюс** и **Ctrl + минус** для пошагового изменения масштаба
- Нажмите **Ctrl + 0**, чтобы восстановить исходный масштаб
- Для горизонтальной прокрутки используйте **Shift + колесо мыши**

Чтобы приблизить область, в режиме просмотра удерживайте **Ctrl**, нажмите ЛКМ и растяните рамку вокруг нужного участка. Начинайте выделение на свободном участке, чтобы не задеть управляющий узел.

Клавиша **S** переключает отображение полос прокрутки. 

## Создание разметки

### Прямоугольник

1. Выберите инструмент прямоугольника или нажмите **T**
2. Нажмите ЛКМ в одном из углов будущей области
3. Не отпуская кнопку, переместите курсор в противоположный угол
4. Отпустите ЛКМ и выберите класс в появившемся окне

Положение углов можно исправить перетаскиванием управляющих узлов.

### Круг

1. Выберите инструмент круга или нажмите **Y**
2. Нажмите ЛКМ в центре объекта
3. Не отпуская кнопку, переместите курсор к границе объекта, задавая радиус
4. Отпустите ЛКМ и выберите класс

Центр круга обозначается крестиком. Для изменения радиуса используйте управляющий узел на окружности.

### Полилиния

1. Выберите инструмент полилинии или нажмите **U**
2. Последовательно нажимайте ЛКМ по границе объекта, добавляя управляющие узлы
3. Создайте не менее трех узлов
4. Замкните контур способом, выбранным в настройках приложения
5. Выберите класс объекта

Последний узел соединяется с первым, образуя замкнутый контур.

### Линия

1. Выберите инструмент линии или нажмите **I**
2. Последовательно нажимайте ЛКМ, задавая управляющие узлы ломаной
3. Создайте не менее двух узлов
4. Завершите построение способом, выбранным в настройках приложения
5. Выберите класс объекта

Завершение построения линии не соединяет ее концы. Для получения замкнутого контура используйте отдельное преобразование в полилинию.

### Как завершить линию или полилинию

Способ выбирается отдельно для каждого инструмента в настройках приложения, в группах **«Замыкание полилинии»** и **«Завершение линии»**.

- **Двойное нажатие ЛКМ** — выполните двойное нажатие ЛКМ для создания последнего узла и завершения построения
- **Последний узел с Ctrl** — удерживая Ctrl, нажмите в положении последнего узла
- **Клавиша C** — поставьте необходимые узлы и нажмите C; новый узел при этом не добавляется
- **Одинарное нажатия по нулевому узлу** — доступен только для полилинии; нажмите по ее первому узлу

**Завершение построения работает только при выборе соответствующего способа в настройках.** Если инструмент не завершается ожидаемым действием, сначала проверьте выбранный способ.

### Точка

1. Выберите инструмент точки или нажмите **O**
2. Нажмите ЛКМ в нужном месте изображения
3. Выберите класс объекта

Размер видимой отметки настраивается отдельно от размера управляющих узлов других фигур.

## Выделение и редактирование

### Выделение фигур

В режиме просмотра выберете фигуру или выберите ее строку в списке фигур.

Для выделения нескольких фигур удерживайте **Ctrl** и выбирайте нужные фигуры. Повторное нажатие с Ctrl снимает выделение с отдельной фигуры. **Ctrl + A** выделяет все фигуры текущего изображения.

### Перемещение фигур

1. Выделите одну или несколько фигур
2. Удерживайте **Shift**
3. Нажмите ЛКМ на выделенной фигуре и перетащите ее
4. Отпустите ЛКМ

Для точного перемещения нажимайте **Shift + стрелка**: выделенные фигуры сдвигаются на один пиксель изображения за нажатие.

**Обычное перетаскивание ЛКМ в режиме просмотра перемещает изображение, а не фигуру.**

### Изменение формы

Наведите курсор на управляющий узел, нажмите ЛКМ и перетащите его. У прямоугольника изменяются углы, у круга — радиус, у линии и полилинии — положение узлов контура.

Для мелких деталей увеличьте изображение. Если трудно захватить узел или ребро, измените соответствующую область захвата в настройках приложения.

### Удаление фигур

Выделите фигуры и нажмите **Delete**. Также можно воспользоваться командой удаления из списка фигур. Ошибочное удаление можно отменить через **Ctrl + Z**.

### Скрытие и показ

Вызовите ПКМ контекстное меню строки в списке фигур и выберите **«Скрыть разметку»** или **«Показать разметку»**. Скрытая фигура остается в списке с пометкой **[скрыто]**; вернуть ее можно через этот список.

Скрытие не удаляет фигуру. Не используйте его вместо удаления ненужной разметки.

### Порядок наложения

Выделите фигуру и нажмите **B**, чтобы переместить ее на задний план относительно других фигур. Это полезно, когда крупная фигура перекрывает мелкие объекты.

## Узлы и операции с линиями

### Добавление управляющего узла

Для линии или полилинии удерживайте **Alt** и нажмите ЛКМ по нужному ребру. Новый узел добавится между соседними узлами.

Другой способ — вызвать ПКМ меню на ребре и выбрать **«Добавить узел»**.

### Удаление управляющего узла

Удерживайте **Alt + Shift** и нажмите ЛКМ по узлу. Также можно вызвать ПКМ меню узла и выбрать **«Удалить узел»**.

Удаление ограничено минимальным количеством узлов: у завершенной замкнутой полилинии должно остаться не менее трех, у линии — не менее двух. Узлы прямоугольника и круга этими командами не удаляются.

### Возобновление редактирования

1. Вызовите ПКМ меню управляющего узла линии или полилинии
2. Выберите **«Возобновить редактирование»**
3. Продолжите построение, добавляя узлы
4. Завершите его выбранным в настройках способом

Возобновление меняет построение существующей фигуры. Ее класс сохраняется, повторно выбирать его не требуется. Выбранный узел определяет место продолжения: проверяйте оставшийся контур перед добавлением новых узлов.

### Преобразование полилинии в линию

Вызовите ПКМ меню на ребре полилинии и выберите **«Полилиния → линия»**. Контур размыкается на указанном ребре и становится незамкнутой линией.

### Преобразование линии в полилинию

Вызовите ПКМ меню на ребре линии и выберите **«Линия → полилиния»**. Для многоугольника нужны не менее трех управляющих узлов. Концы соединяются, образуя замкнутый контур.

### Разрыв линии

Вызовите ПКМ меню на ребре линии, по которому ее нужно разделить, и выберите **«Разорвать линию»**. Операция разделяет линию по выбранному ребру. Если разделение не выполняется, выберите ребро так, чтобы каждая полученная линия могла содержать не менее двух узлов.

### Объединение линий

1. Вызовите ПКМ меню на ребре линии и выберите **«Объединить линии»**
2. Выберите конечный управляющий узел первой линии
3. Выберите начальный управляющий узел второй линии

Выбранные концы соединяются в одну линию. Промежуточные узлы для выбора концов не подходят. Подсказки следующего шага отображаются в строке состояния. **Esc** отменяет режим объединения.

Набор команд контекстного меню зависит от того, вызвано оно на управляющем узле, ребре или самой фигуре.

## Классы объектов

### Список классов проекта

Откройте **Настройка → Свойства проекта**. На вкладке **«Классы»** можно:

- добавить класс кнопкой **+**
- удалить название из списка кнопкой **−**
- переименовать выбранный класс кнопкой **«Редактировать»**
- изменить цвет класса через цветной значок
- изменить порядок кнопками **«Вверх»** и **«Вниз»** или перетаскиванием
- отсортировать список кнопкой **«Сортировать А-Я»**

Сохраните изменения кнопкой **«Применить»** или **«ОК»**. Удаление названия класса из списка и удаление фигур — разные операции.

### Назначение и изменение класса

После создания фигуры появляется окно выбора класса. Выберите нужное название.

Для изменения класса существующего объекта вызовите его контекстное меню и выберите **«Изменить класс»**.

Переименование класса через настройки проекта обновляет его название у существующих фигур загруженных изображений. Если изображения помечены как измененные, сохраните их разметку.

### Цвета и файлы

Фигуры с назначенным цветом класса используют этот цвет. Общие цвета типов фигур задаются в настройках приложения; смена базового цвета не должна использоваться как способ изменить цвет конкретного класса.

Список классов, их порядок и цвета хранятся в **classes.yaml** в рабочей папке. При передаче проекта другому пользователю передавайте этот файл вместе с изображениями и их разметкой.

## Нумерация и рамки

### Видимость номеров

**N** переключает отображение номеров управляющих узлов у выделенных прямоугольников, линий и полилиний. Во время построения линии или полилинии эта клавиша управляет нумерацией создаваемой фигуры.

Общая настройка **«Показывать нумерацию точек»** находится в настройках приложения. Она задает общее отображение; клавиша N позволяет переключать номера отдельных фигур.

### Сдвиг и направление нумерации

- **R** — сдвиг нумерации у выделенных прямоугольников, линий и полилиний по часовой стрелке
- **E** — сдвиг против часовой стрелки

Эти команды не поворачивают фигуру на изображении. **У линии R и E циклически переставляют сами узлы, что может изменить соединяющие их ребра.** Чтобы поменять начало нумерации линии с сохранением ее контура, используйте «Пересчитать нумерацию» в меню конечного узла.

Чтобы назначить начало отсчета у прямоугольника или полилинии, вызовите ПКМ меню нужного управляющего узла и выберите **«Пересчитать нумерацию»**. Выбранный узел становится начальным, с номером **0**. У линии эта команда доступна только на конечных узлах и позволяет выбрать конец, от которого начинается нумерация.

У полилинии в меню узла доступны команды **«Нумерация по часовой стрелке»** и **«Нумерация против часовой стрелки»**. Выбор направления обхода отличается от циклического сдвига номеров клавишами R и E.

### Ограничивающая рамка

**W** переключает ограничивающую рамку у выделенных кругов, линий и полилиний. Это вспомогательный прямоугольник вокруг фигуры.

Рамка и контур фигуры — разные элементы. Скрытие рамки не скрывает саму фигуру. Общая настройка рамок находится в настройках приложения.

## Копирование и история действий

### Копирование и вставка

1. Выделите одну или несколько фигур
2. Нажмите **Ctrl + C**
3. При необходимости перейдите к другому изображению
4. Нажмите **Ctrl + V**

Вставленные на то же изображение фигуры появляются со сдвигом вправо и вниз и выделяются для дальнейшей работы. При переходе к другому изображению при первой вставке сдвига нет.

Фигуры добавляются в конец списка. Буфер обмена содержит разметку в YAML-формате; для обычной работы вручную редактировать его не требуется.

### Отмена и повтор

- **Ctrl + Z** — отменить последнее действие
- **Ctrl + Shift + Z** | **Ctrl + Y** — повторить отмененное действие

У каждого изображения своя история действий. После переключения изображения команды отмены и панель истории относятся к текущему изображению.

Через историю можно отменять, например, создание и удаление фигур, перемещение, изменение узлов и операции с линиями. Если после отмены выполнить новое редактирование, ранее отмененные действия больше нельзя повторить.

История действий не заменяет сохраненный YAML-файл и не предназначена для хранения между запусками программы.

## Сохранение разметки

### Ручное сохранение

Нажмите **Ctrl + S** или выберите **Файл → Сохранить**. Команда сохраняет разметку **текущего изображения**.

Файл создается рядом с изображением с тем же именем и расширением **.yaml**. Например, для **part_001.jpg** используется **part_001.yaml**.

При повторном открытии изображения программа загружает соответствующую разметку автоматически. Если переносите или переименовываете изображение, учитывайте имя и расположение его YAML-файла.

**Изображения с одинаковым именем без расширения в одной папке используют один путь разметки:** например, image.jpg и image.png соответствуют одному image.yaml. Для независимой разметки таких изображений задавайте им разные имена или размещайте их в разных папках.

### Индикаторы в списке файлов

- **Красный значок и звездочка перед именем** — есть несохраненные изменения
- **Зеленый значок** — есть сохраненная непустая разметка, несохраненных изменений нет
- **Серый значок** — файл разметки отсутствует или не содержит разметки

После сохранения пустой разметки значок может остаться серым. Это обозначение отсутствия разметки, а не сообщение об ошибке сохранения.

### Смена папки и выход

При открытии другой рабочей папки или закрытии программы, если остались несохраненные изменения, появляется диалог. Можно сохранить все измененные изображения, отказаться от сохранения или отменить переход/выход.

Проверяйте индикаторы всех измененных изображений: сохранение текущего изображения не сохраняет остальные автоматически.

### Сброс и восстановление

**Правка → Сбросить разметку** удаляет фигуры текущего изображения после подтверждения. Сброс можно отменить через Ctrl + Z; запись очищенной разметки на диск выполняется при сохранении.

**Правка → Восстановить разметку** загружает состояние из YAML-файла. Несохраненные изменения текущего изображения теряются, а его история отмены очищается.

Восстановление читает последнее состояние на диске, в том числе записанное автосохранением. Оно не возвращает более ранние версии файла.

## Автосохранение

### Включение и интервал

1. Откройте **Настройка → Настроить QLabelMe**
2. На вкладке **«Общее»** включите **«Автоматически сохранять разметку»**
3. Выберите интервал: **5, 10, 15 или 30 секунд, 1 или 5 минут**
4. Нажмите **«Применить»** или **«ОК»**

Автосохранение начинает работать после применения настроек. Для его отключения снимите флажок и примените изменения.

### Что сохраняется

Автосохранение записывает только **текущее изображение**, если его разметка изменена. Другие изображения с несохраненными изменениями остаются в памяти до отдельного сохранения.

Используется тот же YAML-файл, что и при Ctrl + S. Отдельная резервная копия и история версий при этом не создаются.

### Когда запись откладывается

Программа пропускает очередную проверку во время загрузки изображения, рисования, возобновленного редактирования, перемещения фигуры, узла или изображения, а также пока нажата кнопка мыши. Большинство открытых диалогов и контекстных меню тоже откладывают запись; окно настроек приложения автосохранение не блокирует.

После завершения действия запись выполняется при следующей подходящей проверке таймера. Поэтому выбранный интервал не является гарантированным сроком записи незавершенной операции.

Чем меньше интервал, тем чаще проверяется возможность сохранения. Для сложной разметки это может увеличить частоту записи на диск. Неизмененная разметка повторно не записывается.

### Состояние внизу окна

- **«Автосохранение: выкл.»** — функция отключена
- **«Автосохранение: вкл.»** — функция включена, первое автоматическое сохранение еще не выполнено
- **«Автосохранение: ЧЧ:ММ:СС»** — время последнего успешного автосохранения
- **«Автосохранение: ошибка»** — сохранить файл не удалось

Наведите курсор на надпись: подсказка показывает, к какому изображению относится последний результат. При переходе к другому изображению отображенное время не подтверждает сохранение нового текущего файла.

При ошибке попробуйте сохранить через **Ctrl + S**, прочитайте сообщение и проверьте доступность рабочей папки для записи.

## Линейка

Линейка измеряет расстояние между двумя положениями на изображении в пикселях, независимо от текущего увеличения. Результат не является расстоянием в миллиметрах или других физических единицах.

1. Нажмите **L** или выберите инструмент линейки
2. Нажмите ЛКМ в начале измеряемого отрезка
3. Не отпуская кнопку, переместите курсор к его концу
4. Отпустите ЛКМ, чтобы зафиксировать измерение

Число рядом с отрезком показывает длину с одним знаком после запятой. Чтобы выполнить новое измерение, снова включите инструмент клавишей L. **Esc** отменяет режим линейки и убирает измерение.

Во время измерения обычные действия с фигурами недоступны. Цвет линейки можно изменить в настройках приложения.

## Настройки

### Настройки приложения

Откройте **Настройка → Настроить QLabelMe**. Параметры сгруппированы по вкладкам.

**«Общее»**:

- шрифт панелей интерфейса
- область захвата управляющего узла и ребра
- сохранение масштаба при переключении изображений
- запоминание видимости меню при перезапуске
- общая видимость нумерации и ограничивающих рамок
- заполнение фигуры при выделении
- включение и интервал автосохранения

Область захвата определяет, насколько близко нужно подвести курсор для взаимодействия с узлом или ребром. Увеличивайте ее, если сложно попасть по тонкому контуру, и уменьшайте, если рядом расположенные элементы мешают выбрать нужный.

**«Вид»** — толщина линий, размер управляющих узлов, размер номеров и размер точечной отметки.

**«Цвет»** — цвета обычного и выбранного узла, номеров и их фона, базовые цвета фигур и цвет линейки. Цвета классов задаются отдельно в настройках проекта.

**«Замыкание полилинии»** и **«Завершение линии»** — способы окончания построения. Они подробно описаны в разделе **«Создание разметки»**.

### Применение изменений

- **«Применить»** — применить настройки и оставить окно открытым
- **«ОК»** — применить настройки и закрыть окно
- **«Отмена»** — закрыть окно без применения новых изменений; ранее примененные кнопкой «Применить» изменения сохраняются

### Настройки проекта

Настройки проекта управляют классами рабочей папки: названиями, порядком и цветами. Подробности приведены в разделе **«Классы объектов»**.

Настройки вида приложения и файлы разметки выполняют разные задачи: изменение размера управляющих узлов или шрифта не заменяет сохранение отредактированных фигур.

## Горячие клавиши

Команды ниже относятся к работе с изображением. При вводе текста в диалогах клавиши могут выполнять обычные действия ввода. Для редактирования разметки сначала вернитесь в область изображения.

### Файлы и интерфейс

| Сочетание | Действие |
| --- | --- |
| Ctrl + O | Открыть рабочую папку |
| Ctrl + S | Сохранить разметку текущего изображения |
| Ctrl + Q | Выйти из программы |
| A | Перейти к предыдущему изображению |
| D | Перейти к следующему изображению |
| Ctrl + M | Скрыть или показать главное меню |
| K | Свернуть или развернуть правую панель |
| S | Скрыть или показать полосы прокрутки |

### Создание и редактирование

| Сочетание | Действие |
| --- | --- |
| T | Выбрать инструмент прямоугольника |
| Y | Выбрать инструмент круга |
| U | Выбрать инструмент полилинии |
| I | Выбрать инструмент линии |
| O | Выбрать инструмент точки |
| C | Завершить линию или замкнуть полилинию, если этот способ выбран в настройках |
| Ctrl + A | Выделить все фигуры текущего изображения |
| Delete | Удалить выбранные фигуры |
| Shift + стрелка | Сдвинуть выбранные фигуры на один пиксель изображения |
| Ctrl + C | Скопировать выбранные фигуры |
| Ctrl + V | Вставить скопированные фигуры |
| Ctrl + Z | Отменить последнее действие текущего изображения |
| Ctrl + Shift + Z | Повторить отмененное действие; доступность системных сочетаний зависит от платформы |
| B | Переместить выбранные фигуры на задний план |

### Масштаб, нумерация и измерения

| Сочетание | Действие |
| --- | --- |
| Ctrl + плюс | Увеличить изображение |
| Ctrl + минус | Уменьшить изображение |
| Ctrl + 0 | Вписать изображение в область просмотра |

| W | Переключить рамку выбранных кругов, линий и полилиний |
| L | Включить инструмент линейки |
| Esc | Отменить режим линейки или объединения линий |

## Управление мышью

Действие зависит от текущего инструмента и положения курсора.

| Действие | Результат |
| --- | --- |
| ЛКМ по фигуре в режиме просмотра | Выделить фигуру |
| Ctrl + ЛКМ по фигуре | Добавить фигуру к выделению или снять ее выделение |
| ЛКМ + перетаскивание в режиме просмотра, вне узла | Переместить изображение |
| Shift + ЛКМ + перетаскивание фигуры | Переместить выделенную фигуру или группу |
| ЛКМ + перетаскивание управляющего узла | Изменить положение узла |
| Alt + ЛКМ по ребру линии или полилинии | Добавить управляющий узел |
| Alt + Shift + ЛКМ по узлу линии или полилинии | Удалить узел, если сохраняется допустимое количество |
| ПКМ по узлу, ребру, фигуре или строке списка | Открыть доступное для выбранного элемента контекстное меню |
| Ctrl + ЛКМ + растягивание рамки на свободном участке в режиме просмотра | Приблизить выделенную область |
| Ctrl + колесо мыши | Изменить масштаб около курсора |
| Shift + колесо мыши | Прокрутить изображение по горизонтали |
| ЛКМ + перетаскивание при выбранном прямоугольнике | Задать противоположные углы |
| ЛКМ + перетаскивание при выбранном круге | Задать центр и радиус |
| Последовательные щелчки ЛКМ при выбранной линии или полилинии | Добавить узлы создаваемой фигуры |
| Щелчок ЛКМ при выбранной точке | Создать точечную отметку |
| ЛКМ + перетаскивание при выбранной линейке | Измерить расстояние |
